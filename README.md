# Python Task Manager

A simple command-line task manager built with Python to practice Python fundamentals and software development basics.

## About

This project is a CLI application for managing daily tasks. It is being developed as a hands-on learning project to practice writing clean, modular, and maintainable Python code.

## Getting Started

### Prerequisites

- Python 3.10 or later
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/TheNimaDev/python-task-manager.git
cd python-task-manager
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### Run the Project

Once the application is implemented, run it with:

```bash
python main.py
```
